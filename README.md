# Learnify – Online Learning Platform

**Theme:** Online Learning Platform
**Course:** Web Dev I – Lab Assignment 5 (Capstone)
**Built with:** HTML5 and CSS3 only (no JavaScript)

## Description
Learnify is a responsive landing page for an online learning platform. It uses semantic HTML5, CSS Grid and Flexbox layouts, hover effects, and a hero animation.

## Sections Implemented
- **Header / Nav:** logo, internal navigation links, skip-to-content link, Login and Sign Up buttons
- **Hero:** headline, tagline, call-to-action button, fade/slide keyframe animation
- **Popular Categories:** six category cards in a CSS Grid
- **Featured Courses:** three course cards with image, instructor, rating, and price
- **Testimonials:** three learner reviews
- **Pricing:** Free, Pro, and Premium plans, with Pro highlighted
- **Contact Form:** labelled fields with required validation and placeholders
- **Footer:** links, contact details, SVG social icons, copyright

## Breakpoints
| Screen | Width | Changes |
|---|---|---|
| Large desktop | 1400px and up | Larger root font size, wider container |
| Desktop | default | 6-column categories, 3-column cards |
| Tablet landscape | 1024px and below | 3-column categories, 2-column cards |
| Tablet portrait | 768px and below | Single-column grids, stacked header and footer |
| Small phone | 480px and below | Smaller fonts, full-width form button |

## Layout Techniques
- CSS Grid for category, course, testimonial, and pricing cards
- Flexbox for the header, footer, form, and alignment
- CSS variables in `:root` for colors, fonts, and spacing
- Relative units (rem, %) with a root font-size
- Media queries for responsive behavior
- Accessibility: semantic tags, alt text, aria-labels, form labels, reduced-motion support
